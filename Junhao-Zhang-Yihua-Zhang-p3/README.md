## Project Overview
This project implements a simple shell in C, providing a basic command-line interface with features such as command execution, changing directories, and input/output redirection.

## Compilation Instructions
1. Open a terminal.
2. Navigate to the project directory.
3. You can use make command in the makefile to compiling the program
4. then make sure run the shell.c on the vcf node, by using $ssh vcf0
5. If you get into cf node, then you can run your progam
6. If you make "fork bomb" on the odin server. Use this command eliminate
    $ killall -u (~MyID~)
