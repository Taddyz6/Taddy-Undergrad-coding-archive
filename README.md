## 📖 About This Repository

This repository contains a selection of code, coursework, programming assignments, experiments, and personal projects completed during my undergraduate studies.

It was created to preserve part of my academic programming journey, document the technologies I explored, and provide a historical record of my development as a programmer.

> [!IMPORTANT]
> This repository does **not** contain every project or every piece of code I completed during my undergraduate studies.
> It only includes portion of the materials that were preserved and considered suitable for public archiving.

Some projects were completed several years ago. Their code style, dependency versions, documentation, and project structure may therefore differ significantly from current development practices.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Taddyz6/Taddy-Undergrad-coding-archive.git
```

Enter the repository directory:

```bash
cd Taddy-Undergrad-coding-archive
```

Browse the available projects:

```bash
ls
```

Because this repository contains multiple independent projects, there is no single command for installing or running everything.

Enter the relevant project directory and inspect its source code, comments, documentation, and configuration files before running it.
